# 사전 확인

- 저장소 루트의 `AGENTS.md`와 [Git 컨벤션](../git-conventions/SKILL.md)을 확인한다.
- `git status --short`, `git diff`, `git diff --cached`로 대상 변경을 확인한다.
- 요청 범위의 파일만 명시적으로 스테이징하고 사용자 변경을 덮어쓰지 않는다.
- [검증 컨벤션](../../../docs/conventions/verification.md)에 따라 검증한다.
- 메시지만 요청받았다면 실제 커밋은 수행하지 않는다.

# 커밋 작성

- 커밋 메시지는 `타입: 변경 요약` 형식으로 한국어 작성
- 커밋은 제목만 작성하고 본문과 이슈 참조 문구(`Refs #번호` 등)는 작성하지 않음
- 변경 성격에 맞는 타입 사용: `feat`, `fix`, `refactor`, `docs`, `test`, `chore`, `style`
- 예시: `feat: 로봇 정지 명령 처리 추가`
- 타입 뒤 괄호 사용 금지: `feat(친구): ...` 형식 사용 금지

# 어투

- 변경 내용을 간결한 개조식 및 명사형으로 작성
- 목록 사용 시 하이픈으로 통일하고 중단점(·) 혼용 금지

# 에이전트 표기 금지

- 제목과 본문에 에이전트가 작성하거나 커밋했다는 문구 추가 금지
- 에이전트 이름, AI 생성 문구 및 에이전트 공동 작성자 표기(`Co-authored-by`) 추가 금지
