# ADR 0011: 로봇별 배정과 분산 ROS 실행

- 상태: 구현 중
- 관련 이슈: #51
- 기반: [ADR 0010](0010-runtime-lease-failover.md)

## 사용자 흐름과 메시지 흐름

Fleet에서 로봇을 생성하면 API가 등록 설정을 저장한다. 분산 모드의 서버 pulse가
수용 한도 안에서 로봇을 배정하고, 해당 서버만 실행 UUID의 ROS 경로를 생성한다.
관측과 준비 보고가 확인된 뒤 명령을 허용한다. 다른 서버의 로봇 이동은 유지한다.
명령은 대상 서버와 실행 UUID 및 배정 버전을 포함한다. 기존 cmd_id와 outbox 원문은
인계 시 다시 쓰지 않는다. 다른 서버 대상 명령은 정상적으로 건너뛴다.

## 소유권

서버 UUID는 프로세스 수명을, 실행 UUID는 로봇의 한 번의 실행을 나타낸다. 배정할 때마다
새 실행 UUID와 증가한 배정 버전을 저장한다. 같은 서버로 돌아와도 과거 UUID를 재사용하지
않는다. simulation_runtime_id는 분산 모드에서 로봇 실행 UUID를 전달한다.

서버 pulse는 2초 주기이며 서버와 로봇별 lease의 기본 TTL은 12초다. 로컬 기한은
요청 시작 BOOTTIME + TTL - 2초다. 만료 후에는 같은 실행 UUID를 갱신하거나 되살리지 않는다.
DB가 느리거나 끊기면 현재 기한만 유지하고 만료된 실행을 중단한다.
Fleet 잠금은 배정과 이전 및 명령 접수 경쟁을 조정한다. 잠금을 보유한 채 HTTP를 호출하지 않는다.

## 배정과 해제

ACTIVE이며 lease가 유효한 서버 중 배정 수/수용 한도가 가장 낮은 서버에 새 로봇을 배정한다.
한도를 넘기지 않으며 자리가 없으면 UNASSIGNED로 유지한다. 소유권은 DB에 남기고
ASSIGNED → RELEASING → UNASSIGNED → 새 ASSIGNED 순서로 이전한다.

정상 재분배는 최근 idle 관측, 마지막 명령 이후 10초 경과와 미수신 유효 outbox 부재를
확인한 뒤 요청한다. RELEASING부터 새 명령을 거부한다. ROS executor가 실제 idle을
다시 확인하고 명령 경로와 로봇을 해제한 뒤 종료 확인을 보고한다. 종료 확인 전에는 새
소유자를 배정하지 않는다. 이동 중에는 정상 이전을 기다리며 삭제 요청은 이동도 중단한다.
한 번에 하나의 정상 이전을 진행해 아직 반영되지 않은 목적지 부하로 과잉 해제하지 않는다.

DRAINING 서버에는 새 로봇을 배정하지 않는다. 새 서버가 추가돼도 이동 중 로봇을 강제로
중단하지 않는다. 장애는 기존 lease 만료 후 해당 서버의 로봇만 인계한다. 재시작 위치와
배터리는 등록 기본값이며 과거 이동은 재개하지 않는다. 실제 하드웨어 정지와 시계 조건은
ADR 0010의 한계를 유지한다.

## 도입과 PR 경계

1. V15, 서버 및 배정 API와 실제 PostgreSQL 계약 테스트
2. ROS 및 명령, 보고와 온라인 및 최신 상태 조회 연결
3. 격리된 1 → 3 → 1 증설 및 축소와 장애 검증 및 실행 문서

SIMULATOR_DISTRIBUTED_ENABLED는 전체 연결 완료 전후 모두 기본 false이며 명시적으로
활성화한다. 명령 영속 경로의 기본값도 유지한다. 기존 런타임을 모두 종료하고 마이그레이션과
API 및 ROS를 순서대로 교체한다. 분산 모드를 사용한 Fleet은 레거시 등록으로 소유권을
덮어쓰지 못하게 한다. 정적 Bridge와 분산 모드는 같은 Fleet에 혼합하지 않는다.
서버별 영속 볼륨은 독립적이며 이전 결과는 원래 서버의 디스크가 복구된 뒤에도 회수한다.

## 1차 계약 검증

DistributionPostgresTest는 전용 PostgreSQL의 임시 스키마에서 V15를 적용하고 실제 Fleet
잠금 대기를 확인한다. 배정 상한, 만료 서버의 재활성화 거부, 영향 없는 실행 UUID 유지,
다른 소유자 및 이전 실행의 종료 확인 거부, 삭제 tombstone과 트랜잭션 롤백을 검증한다.
DistributionControllerTest는 서버 토큰이 없는 관리 요청을 서비스 호출 전에 거부한다.
이 PR만으로 분산 실행을 활성화하지 않으며 ROS 및 조회 경로 연결은 다음 PR에 포함한다.
