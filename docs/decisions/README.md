# Architecture Decision Records

미래 작업자가 다시 논의할 가능성이 있는 구조적 결정을 저장합니다.

## 작성 기준

다음 중 하나가 바뀌면 ADR을 검토합니다.

- 서비스 경계, 패키지 구조, 런타임 또는 상태 관리 방식
- DB 스키마 소유권과 마이그레이션 정책
- Kafka/HTTP/SSE/WebSocket 계약 또는 폴백 정책
- 입력 의미, 상태 정규화, 사용자에게 표시하는 판단 기준

좁은 버그 수정이나 이미 기록된 결정을 따르는 변경에는 새 ADR을 만들지 않습니다.

## 형식

파일명은 `NNNN-kebab-case-title.md`를 사용하고 상태, 맥락, 결정, 결과, 검증을 포함합니다.
기존 기록을 삭제하지 말고 새 ADR에서 대체 관계를 명시합니다.
